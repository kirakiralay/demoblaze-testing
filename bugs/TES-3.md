# Форма авторизации: атрибут for у label не совпадает с id поля

## Описание
В DevTools во вкладке Issues обнаружена ошибка некорректного использования 
атрибута `for` у элементов `<label>` формы авторизации. Затронуто 3 элемента.

## Предусловие
Открыт браузер Google Chrome с включёнными DevTools (F12 → Issues).
Пользователь находится на странице demoblaze.com

## Шаги воспроизведения
1. Открыть https://demoblaze.com
2. Открыть DevTools → вкладка Issues
3. Нажать кнопку "Log in" в шапке сайта

## Ожидаемый результат
Форма авторизации не содержит ошибок, атрибуты `for` у `<label>` 
корректно ссылаются на id полей формы

## Фактический результат
В DevTools → Issues появляется ошибка:
`Incorrect use of <label for=FORM_ELEMENT>`
Ошибка обнаружена на 3 элементах формы авторизации.
Последствия: автозаполнение формы может работать некорректно, 
сайт недоступен для пользователей со скринридерами

## Среда
- ОС: Windows 10, 64bit
- Браузер: Google Chrome 149.0.7827.201 (64 бит)
- Страница: https://demoblaze.com
