# [API] Эндпоинт /login возвращает статус 200 при неверном пароле вместо 401

## Описание
При авторизации на сайт с неправильным паролем возвращается успешный статус 200

## Предусловие
Пользователь находится на странице demoblaze.com, не авторизированным

## Шаги воспроизведения
1. Открыть Postman
2. Создать POST запрос на https://api.demoblaze.com/login
3. В Body → raw → JSON вставить:
   {"username": "kiralay", "password": "неверныйпароль"}
4. Нажать Send

## Ожидаемый результат
Вывод окна с ошибкой 'неверный пароль', вернется статус 401

## Фактический результат
В Body возвращается {"errorMessage": "Wrong password."} со статусом 200 OK вместо 401 Unauthorized

## Среда
- Инструмент: Postman
- Эндпоинт: POST https://api.demoblaze.com/login

## Приоритет
Medium

## Severity
Major
